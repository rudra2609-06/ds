A vector store is system designed to store and retrieve data represented as numerical vectors

key features of vector stores:
1.Storage:- Helps in storing vectors and its meta-data. Can be stored in-memory (RAM) or on-disk(hard drive)
2.Similarity Search:- Helps in retrieving the most similar vector with respect to query vector
3.Indexing:- For fast searching
4.CRUD Operations

Use Cases:
1.Seamantic searching
2.RAG
3.Recommender Systems
4.Image/Multi-media Search

Vector Store V/S Vector DataBase

If system provide just storage and retrival of vector it is just vector store (light weight)

But if provides Role Based Control, ACID transactions, Concurrency Control , Distributed Arc they are Vector DataBase (Heavy)

Every Vector DataBase is Vector Store
